# Shooper Nova Patch r3 (Game Version Steam Build 25656630)

`Shooper Nova`의 기존 한국어 리소스를 원문 기준으로 다시 번역·검수한 Windows x64용 교체 패치입니다.

## 주요 변경 사항

- 842개 사용자 노출 항목의 ID와 순서를 원문 인벤토리에 다시 대응했습니다.
- 대사, 메뉴, 설정, 전투 및 시스템 UI의 용어와 문맥을 원문 기준으로 검수했습니다.
- 자동 사격 상태값을 `활성화` / `비활성화`로 수정해 조합된 UI가 `자동 사격: 활성화` / `자동 사격: 비활성화`로 표시되도록 바로잡았습니다.
- 최신 Parr0t 체크포인트와 Windows 설치기 계약을 적용했습니다.
- 설치, 업데이트, 상태 확인, 원본 복원을 한 설치기에서 지원합니다.
- 원본 언어 리소스의 크기와 SHA-256이 다른 게임 빌드는 파일을 변경하기 전에 중단합니다.

## 지원 버전

- Steam App ID: `2853160`
- Steam Build ID: `25656630`
- Windows x64
- Unity `2022.3.62f1`

다른 빌드에는 설치하지 마세요. 게임 업데이트 후 설치기가 지원하지 않는 빌드라고 알리면 새 패치를 기다려 주세요.
